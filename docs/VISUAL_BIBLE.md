## 1. Core Identity

| Pillar | Spec |
|--------|------|
| Tagline | Rewrite reality. Outsmart the Compiler. |
| Player role | Not the hero. The editor. The cold boot. |
| Palette | Electric violet / magenta energy on deep blue-black wet streets |
| Dual world | Layer 1 2026 Vesper City (neon megacity) vs Layer 0 1994 Necropolis (gothic ink ruins) |
| Bleed | Vertical lightning / purple tear between timelines |
| Tone | Cyber-noir, high contrast, glitch, rain, reflective asphalt |

**Non-negotiable colors**
- Causal energy: `#C44DFF` – `#9B2DFF` (violet-magenta glow)
- Night city base: near-black blues, wet purple reflections
- Layer 0 accent: colder ink purple / decay
- UI: thin violet holographic lines, not thick sci-fi chrome

## 2. Characters

### Sable
- Young woman, dark hair, glitch/corruption on face and hair
- Purple digital decay, not blood horror
- Role: only constant in a corrupted script; guide; unreliable truth
- Quote lock: *"You're not supposed to win by being right. You win by being unreadable."*
- Mid-game twist support: *"Project Cold Boot already succeeded."*

### Auditor Unit
- Male silhouette, dark suit, face digital/glitched or featureless screen
- Standing, still, predictive presence
- HUD: prediction %, "CAUSALITY LOCK ACTIVE"
- Behavior read: predicts, adapts, removes possibilities — never fights fair

### Player (first person)
- Gloved hands (dark tactical / leather)
- Tools: handheld scanner, lens, glyph emitter, gravity anchor device
- Occasional hooded/coat silhouette in third-person key art

**MVP**
1. **Noctro-Glyph** — draw causal links between anchors
2. **Gravity Anchor** — attach, pull, swing, redirect momentum
3. **Restorer's Lens** — reveal hidden anchors, weak points, alternate paths

**Expansion tools (from boards)**
4. **Version Fork** — split reality into temporary branches (door closed/open, bridge intact/collapsed)
5. **Memory Spike** — inject old timeline memories into current reality

UI icons: minimal line icons, violet on dark, numbered 1–5 in FPS HUD.

## 8. Puzzle / System Visual Language

- **Causal Circuit**: flowchart nodes (Power Plant → Transit → Population → Gate)
- **Contradiction Engine**: impossible dual states (locked AND unlocked)
- **Version Fork**: parallel object states side by side
- Graph overlays always violet, thin, luminous — never muddy green or orange

## 9. Implementation Rules

1. Gray-box is temporary; materials must trend toward wet night + violet emission.
2. No generic orange cyberpunk neon as primary accent.
3. Dual-layer bleed uses vertical purple lightning tear (see dual-reality board).
4. Sable and Auditor must remain recognizable from the provided portraits.
5. Districts are the content spine for campaign structure.
