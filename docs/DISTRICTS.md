## Travel methods (canon)
- Ghost Rail — fast travel between unlocked stations
- Reality Tear — short unstable jumps
- Fall — drop between layers (not all paths survive)
- Anchor Shift — shift active anchors to open routes

## Environmental hazards
- Causal Storm — random causal shifts
- Memory Rain — exposure causes memory bleed
- Null Zones — anchors cannot exist
- Echo Waves — old actions repeat
