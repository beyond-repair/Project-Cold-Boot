# How to Play (Cycle 6+)

## Run
Godot 4.2+ → open `godot/` → F5

## Controls

| Input | Action |
|-------|--------|
| E | SCAN |
| LMB | SNAP |
| Space | SUNDER |
| R | Reset |
| Esc | Pause |
| H | Toggle history |
| 1 / 2 / 3 | Kernel |
| N | Next room (after win) |
| **F5** | **Save run** |
| **F9** | **Load run** |

Save file: `user://coldboot_run.save`

Bleed intensity on the domain-warped compositor rises after SCAN and again on win.
