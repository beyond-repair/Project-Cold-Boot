# Gear of the Ancients

## Item #1 — Shadow-Skin
Semi-organic polymer suit. Absorbs light. Kinetic Burst via Android touch gestures. Enhances Noctro-Glyph execution speed during stealth. Field Freeze operator equivalent.

## Item #2 — Noctro-Glyph
Palm-sized obsidian shard with shifting sigils. Symbolic processor bridging MysTech (Layer 0) and modern infrastructure (Layer 1).

**Abilities**
- Resonance Scan: Reveal buried structures / entities / energy nodes
- Glyph Execution: Gesture-driven patterns (swipe chains, hold-release)
- Reality Desync: Temporary Layer 0 overlay for traversal and interaction

**Progression**: Tiered (basic interaction → environmental rewrite → entity interaction → localized code rewrite). Framed as learning a dangerous, semi-understood ancient language.

## Item #3 — Dimensional Anchor (Phase-Tether Harness)
Collapsible obsidian-and-brass gauntlet with retractable crystalline tethers.

**Abilities**
- Vector Anchor: Lock to surfaces or hidden Layer 0 anchors
- Phase-Tether: Dual-layer tethers for pass-through and vertical bridging
- Momentum Cascade: Chain anchors for high-velocity traversal (SUNDER synergy)

**Progression**: Basic pull/swing → dual-layer + phase → cascade chaining → permanent player-authored vertical highways.
