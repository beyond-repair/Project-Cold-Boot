# Vertical Slice — Visual Checklist

Match these moments from the provided GDD + moodboard images.

## Required Visual Beats

1. **Establishing / Dual Reality**
   - Player sees both 2026 neon street and 1994 gothic ruins.
   - At least one visible lightning bleed seam.

2. **SCAN**
   - Restorer’s Lens or handheld device activates.
   - 3–5 purple nodes / anchors appear over the environment.
   - Hidden geometry or Layer 0 elements revealed.

3. **SNAP**
   - Player draws luminous purple edges between nodes.
   - Graph is readable at a glance (nodes + directed links).

4. **Auditor Appearance**
   - Suit figure with glitch/scan-line treatment.
   - Simple prediction or lock indicator (even if placeholder UI).

5. **SUNDER**
   - Chain executes with clear violet energy travel and impact.
   - Environment reacts (doors open, platforms shift, bleed intensifies).

6. **Sable**
   - Brief presence or dialogue trigger.
   - Corrupted-code visual treatment.

7. **Escape**
   - Use of Dimensional Anchor or desync to leave the rewritten space.
   - Final view of the changed room / street.

## Gray-Box Acceptance Criteria

- Causal graph is the most readable element on screen during SNAP/SUNDER.
- Layer 0 and Layer 1 are distinguishable without UI text.
- Auditor feels systemic, not like a conventional shooter enemy.
- One “reality just rewrote itself” moment is unmistakable.

## Out of Scope for Slice

- Full character animation
- Final lighting / post-process
- Complete Sable model
- Multiple Auditor variants
- Production VFX library

Art polish follows validated fun + determinism.
