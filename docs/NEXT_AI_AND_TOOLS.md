# Where to go next (without pretending chat = full studio)

You are often on **mobile**. No AI can fully replace a computer for Godot playtest, Blender, or Steam. Use the right tool for each job.

## 1. Keep design / code iteration (chat AIs)

Use **Grok, ChatGPT, Claude, Gemini**, etc. for:

- More district puzzles, dialogue, Sable lines
- GDScript snippets and bug fixes (paste errors from Godot)
- Steam page copy, trailer script, pitch deck text
- Balancing threat tables and Auditor rules

Point them at this repo + `docs/VISUAL_BIBLE.md` + `docs/MECHANICS.md`.

## 2. 2D art (can start on mobile)

- **Grok Imagine / image AIs**: more key art, UI icons, graffiti, loading screens matching violet dual-reality look
- Upscalers / editors on phone for mockups

Still import into Godot on a PC later.

## 3. 3D models (needs a computer eventually)

No chat AI ships production-ready Godot characters by itself.

Options:

| Path | Tool | Notes |
|------|------|--------|
| Generate mesh attempts | Meshy, Rodin, Luma Genie, CSM.ai, Tripo | Output GLB; clean up on PC |
| No Blender skill | Godot Asset Library + itch/Unity-cyber kits retinted | Fastest for streets |
| Learn light 3D | Blender on any PC (library PC works) | Follow "export GLB to Godot" tutorials |
| Paid | Commission on Fiverr/ArtStation using your boards as ref | Best quality match |

**Prompt anchor for any 3D/image AI:**  
"Project Cold Boot: wet night cyber-noir, electric violet causal energy, dual timeline 2026 Vesper / 1994 gothic Necropolis, Sable glitch-corrupted young woman, Auditor dark suit digital face, high contrast, rain reflections — match provided concept boards."

## 4. Must use a computer (any PC)

1. Install Godot 4.2+
2. Clone repo, open `godot/`, F5
3. Drop `.glb` into `godot/assets/`, instance in scenes
4. Export project when ready
5. Steamworks upload

Library / school / friend PC is enough for playtest sessions.

## 5. Suggested order for you

1. Mobile: keep writing story/puzzles with a chat AI; generate 2D icons/key art
2. Next PC session: play current build, note 5 friction points
3. Feed those notes back to a chat AI for code patches
4. When ready for look-up: asset kit or Meshy-style GLB for one street + Sable proxy
5. Only then worry about Steam

## 6. Do not expect

- An AI that finishes the entire game with zero PC time
- Chat-only Blender-quality final art
- "100% shipped" without playtest on real hardware
