# Project Cold Boot

**You are not the hero. You are the cold boot.**

Godot 4 reality-editing puzzle: **SCAN → SNAP → SUNDER** across dual timelines (Vesper City 2026 / Necropolis 1994).

## Play (needs a PC once)

1. Install Godot 4.2+
2. Open the `godot/` folder as the project
3. F5

## Mobile / chat workflow

Design and code can continue in chat. Running the game, exports, and final 3D need a computer.  
Read **`docs/HANDOFF.md`** and **`docs/NEXT_AI_AND_TOOLS.md`**.
