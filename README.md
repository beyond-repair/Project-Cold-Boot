# Project Cold Boot

**You are not the hero. You are the cold boot — the first draft the system never meant to survive.**

First-person reality-editing action-puzzle game. Godot 4.x. Dual-reality (1994 Necropolis / 2026 Vesper City). Core loop: **SCAN → SNAP → SUNDER**.

**Public repo**: https://github.com/beyond-repair/Project-Cold-Boot

## Foundation 1.0 — Complete

This repository is a **finished foundation**:

- Playable vertical slice (two rooms, Kernels, Auditor, Sable, save/load, options)
- Dual SubViewport + domain-warped compositor/shaders
- DLRSE-style log/validate/commit simulation (GDScript)
- Art direction locked to the project reference images
- Full architecture, design Bible, Steam preparation package, roadmap to commercial 1.0

**Read**: [`docs/COMPLETE.md`](docs/COMPLETE.md) — what is done vs what remains for a Steam release.

## Play

1. Install Godot 4.2+
2. Open the `godot/` folder
3. F5
4. ENTER THE MANUSCRIPT

| Input | Action |
|-------|--------|
| E | SCAN |
| LMB | SNAP |
| Space | SUNDER |
| 1 / 2 / 3 | Kernel |
| N | Next room |
| F5 / F9 | Save / Load |
| Esc | Pause |
| R | Reset |
