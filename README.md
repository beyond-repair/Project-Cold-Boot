## ▌ VISUAL WORKFLOW — VERSION FORK

```text
  ┌─────────────┐
  │ 1. SCAN     │  Read the current reality layer
  └──────┬──────┘
         ▼
  ┌─────────────┐
  │ 2. SNAP     │  Capture a parallel state (version fork)
  └──────┬──────┘
         ▼
  ┌─────────────┐
  │ 3. SUNDER   │  Tear the fabric — swap timelines
  └──────┬──────┘
         ▼
  ┌─────────────┐
  │ 4. EDIT     │  Rewrite objects, NPCs, logic
  └──────┬──────┘
         ▼
  ┌─────────────┐
  │ 5. BOOT     │  Cold start into the new reality
  └─────────────┘
```
